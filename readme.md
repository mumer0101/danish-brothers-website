# Danish Brothers Company Website

This is a responsive, multi-section website built in 2024 for **Danish Brothers**, a business specializing in the import, export, and engineering of used machinery and manufacturing equipment.

## Project Overview

The website highlights:
- Company branding and services
- Product categories with image carousels
- Mobile-friendly responsive design
- Sections for Used Construction, Agricultural, Industrial Machines, and more
- A showcase of the company’s manufacturing plant

## Technologies Used

- HTML5 / CSS3
- Bootstrap 4
- Swiper.js (image slider)
- Font Awesome
- AOS.js (scroll animations)
- Google Fonts
